SHIVAI on GitHub Pages
1. Sign up at github.com (free), then click + > New repository. Name it shivai (Public). Create.
2. On the repository page click "uploading an existing file". Drag in ALL files from this folder
   (index.html, client.js, api-bridge.js, hero-food.jpg, .nojekyll). Click Commit changes.
3. Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root). Save.
4. After about 1 minute your site is at https://YOUR-USERNAME.github.io/shivai/
5. In Apps Script keep the latest Code.gs deployed as a web app, "Who has access" = Anyone.
